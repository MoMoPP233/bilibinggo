# Binggo 逐项人工验收计划

对应 `PROJECT_FUNCTION_INVENTORY.md` 的 137 个功能编号。全部初始状态：未测试。静态阅读和历史自动测试不能代替用户验收。

本轮未运行扫描、参与、B站/LLM请求或安装程序，也未修改真实Profile。以下步骤是今后用户授权下的验证建议，不是已经执行的操作。

安全前置：先备份；以临时数据根/fixture优先；屏蔽真实B站、LLM和通知HTTP；不要将mock接到真实服务。真实账号验证需单独批准。记录浏览器端口、runtime Profile、UID与instance_id；敏感信息不粘贴。

建议第一项：UI-001，当前实例只读查看活动列表、搜索/筛选/翻页，对比总数，不点击扫描或参与。它能先验证账号与展示是否一致，且不直接触发B站mutation。
